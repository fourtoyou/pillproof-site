# PillProof

ตู้จ่ายยาอัจฉริยะสำหรับผู้สูงอายุ — จ่ายซองยาทีละซองลงถาดรับ ยืนยันด้วยการคืนซองเปล่า และแจ้งเตือนลูกหลานผ่าน LINE

เว็บไซต์โปรเจกต์ หน้าเดียว มีโมเดล 3 มิติโต้ตอบได้ (three.js)

## เปิดดูในเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่ชื่อ `pillproof-site` บน github.com (Public)
2. รันคำสั่งที่บอกไว้ในหน้า repo ที่เพิ่งสร้าง (ส่วน "push an existing repository")
3. ไปที่ Settings → Pages → Source เลือก `Deploy from a branch` → branch `main` → folder `/ (root)` → Save
4. รอประมาณ 1 นาที เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/pillproof-site/`
